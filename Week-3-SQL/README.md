# Week 3 – SQL for Data Analytics

## Objective
Import the cleaned e-commerce dataset into SQLite and perform SQL queries to retrieve, filter, sort, group, and aggregate data.

## Tasks Performed
- Imported cleaned dataset into SQLite
- Executed SELECT queries
- Applied WHERE filtering
- Used ORDER BY sorting
- Performed COUNT, SUM, and AVG aggregations
- Used GROUP BY for product-level analysis
- Generated SQL-based business insights

## SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- COUNT()
- SUM()
- AVG()
- GROUP BY

## Key Findings
- Dataset contained 1,200 order records.
- Total quantity sold was 3,535 units.
- Chairs had the highest quantity sold.
- Phones had the highest average product price.
- Printers recorded the highest number of orders.

- DB Browser for SQLite
- SQLite
- Microsoft Excel
- Microsoft Word
