# Week 2 – Exploratory Data Analysis (EDA)

## Objective

Perform Exploratory Data Analysis (EDA) on the cleaned dataset to identify trends, relationships, outliers, and business insights.

## Analysis Performed

- Descriptive Statistics
- Correlation Analysis
- Outlier Detection (IQR Method)
- Product Revenue Analysis
- Referral Source Analysis
- Payment Method Analysis
- Monthly Sales Trend Analysis
- Box Plot Visualization

## Key Findings

- 1,200 transaction records analyzed
- 8 outlier transactions identified
- Chair generated the highest product revenue
- Instagram generated the highest referral-source revenue
- UnitPrice showed the strongest correlation with TotalPrice

- EDA Workbook
- EDA Report
